📖 מדריך הדפסה

איך פותחים את הקבצים

ההורדה היא קובץ ZIP. מחלצים אותו ומקבלים: trip3d.3mf (מומלץ: חלקים וצבעים מוגדרים מראש), all_in_one.stl (הכול בצבע אחד), וקבצי STL נפרדים לכל צבע.

סלייסראיך מייבאים
Bambu Studio / OrcaSlicerFile ← Import ← בחרו את ה-3MF. כל חלק מופיע כאובייקט נפרד, וצבעו מוצג. הקצו לכל צבע חומר (Filament) מה-AMS.
PrusaSlicerFile ← Import ← 3MF/STL. להדפסה מרובת צבעים: בחרו אובייקט ← Extruder בחלון ההגדרות.
CuraFile ← Open File(s) ← all_in_one.stl (או הקבצים הנפרדים). Cura לא קורא צבעים מ-3MF.

הגדרות כלליות מומלצות

דיזה 0.4 מ״מ, גובה שכבה 0.2 מ״מ, 3 קירות, מילוי 15%–20%, בלי תמיכות (המודלים נבנו כך שלא נדרשות), ו-Brim לחלקים קטנים. הדפיסו את המודל כפי שהוא, ללא סיבוב.

טיפים לפי כלי

  • מזכרת עם מעמד: הכיתוב והדגל בולטים כ-1 מ״מ. להדפסה נקייה של טקסט קטן הורידו מהירות ל-40–60 מ״מ/ש׳. עם עמודים מתחת למדינה יש גישור קצר: מהירות גישור נמוכה עוזרת.
  • קוד QR: הלוחית נפרדת. הדפיסו בניגודיות גבוהה (צבע בהיר ורקע כהה או להפך), ובדקו בסריקה לפני שמדביקים.
  • מחזיק מפתחות / קישוט: 4 קירות או מילוי 100% בטבעת, כדי שלא תישבר.
  • מגנט למקרר: בגב יש כיס למגנט עגול. אפשר להכניס את המגנט בהשהיה (Pause at layer) מיד אחרי שהכיס נסגר, או להדביק בדבק מאחור. בדקו שגודל המגנט תואם למה שבחרתם.
  • פאזל: מדפיסים את החלקים שטוחים. הרווח בין חלקים הוא כ-0.3 מ״מ. אם הם הדוקים מדי, שייפו קצת או הקטינו ל-99% ב-X/Y. המגש (אם בחרתם) נפרד ומיועד להחזיק את החלקים.
  • מעמד לטלפון: מדפיסים כמו שהוא. מתאים לטלפון בעובי של עד כ-14 מ״מ כולל מגן.
  • הרבה צבעים: אם יש לכם מדפסת עם AMS, השתמשו ב-3MF והקצו חומר לכל חלק. אחרת, הדפיסו בצבע אחד או החליפו חומר ידנית בשכבה מסוימת (Color change).

בעיות נפוצות

  • טקסט או פרטים לא יוצאים: הגדילו את המודל (בחרו משטח גדול יותר), קצרו את שם הטיול, או עברו לדיזה 0.2.
  • הדפסה עקומה בפינות: הוסיפו Brim, נקו את המשטח, והעלו טמפרטורת מצע.
  • המודל הוקטן: האתר מקטין כדי להתאים למשטח שהגדרתם. בחרו משטח גדול יותר אם אפשר.

בחלון ההורדה מופיעה בדיקת שלמות אוטומטית. אם היא מציגה אזהרה, הסלייסר בדרך כלל מתקן זאת, אבל כדאי לעבור על תצוגת השכבות.

📖 Print guide

Opening the files

The download is a ZIP. Extract it to get trip3d.3mf (recommended: parts and colors are preset), all_in_one.stl (everything in one color) and separate STL files per color.

SlicerHow to import
Bambu Studio / OrcaSlicerFile → Import → pick the 3MF. Each part is a separate object with its color. Assign each color a filament from your AMS.
PrusaSlicerFile → Import → 3MF/STL. For multicolor: select an object → choose the Extruder in the settings panel.
CuraFile → Open File(s) → all_in_one.stl (or the separate files). Cura doesn't read colors from 3MF.

Recommended general settings

0.4 mm nozzle, 0.2 mm layers, 3 walls, 15–20% infill, no supports (models are built so none are needed), and a brim for small parts. Print the model as is, without rotating it.

Tips per tool

  • Souvenir with stand: lettering and flag stand about 1 mm tall. For clean small text slow down to 40–60 mm/s. With pillars under the country there is a short bridge: a low bridging speed helps.
  • QR code: the plate is separate. Print with high contrast (light on dark or the reverse) and test-scan it before gluing.
  • Keychain / ornament: use 4 walls or 100% infill on the ring so it doesn't snap.
  • Fridge magnet: the back has a pocket for a round magnet. Insert it with a pause (Pause at layer) right after the pocket closes, or glue it on the back. Check the magnet size matches your choice.
  • Puzzle: print the pieces flat. The gap between pieces is about 0.3 mm. If they are too tight, sand lightly or scale to 99% in X/Y. The tray (if chosen) is separate and holds the pieces.
  • Phone stand: print as is. Fits phones up to about 14 mm thick including a case.
  • Many colors: with an AMS printer use the 3MF and assign a filament per part. Otherwise print in one color or swap filament manually at a layer (Color change).

Common problems

  • Text or details don't print: make the model bigger (choose a larger bed), shorten the trip name, or use a 0.2 nozzle.
  • Warping at corners: add a brim, clean the bed and raise the bed temperature.
  • Model was scaled down: the site scales to fit the bed you chose. Choose a larger bed if possible.

The download window shows an automatic integrity check. If it shows a warning, slicers usually repair it, but review the layer preview.
