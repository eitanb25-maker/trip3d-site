# מזכרות תלת-ממד – גרסת Netlify

אתר + שרת (Netlify Functions) עם התחברות אמיתית, תפקידים, מכסות הורדה, קודי הזמנה, התראות, סטטיסטיקות ולוח בקרה.

## מה יש בתיקייה
| קובץ | תפקיד |
|---|---|
| `public/index.html` | האתר עצמו (כל הכלים) |
| `public/admin.html` | **לוח הבקרה** (`https://האתר-שלך/admin.html`) – נפתח רק למנהלים ולעורכים |
| `public/shim.js` | חיבור האתר לשרת |
| `public/health.html` | **בדיקת תקינות**: מראה מה מוגדר ומה חסר |
| `netlify/functions/api.mjs` | השרת: התחברות, הורדות, מכסות, משתמשים, הגדרות |
| `netlify/functions/weekly.mjs` | דוח שבועי אוטומטי (התראה פעם בשבוע) |
| `netlify/lib/lib.mjs` | אחסון, סטטיסטיקות והתראות |
| `netlify.toml`, `package.json` | הגדרות פריסה |

## פריסה ב-Netlify (הדרך המומלצת: GitHub)
1. פתחו חשבון חינם ב-GitHub וצרו מאגר (repository) חדש. העלו אליו **את כל התוכן של התיקייה הזו** (גרירה של הקבצים בדף "uploading an existing file" מספיקה).
2. ב-Netlify: **Add new site → Import an existing project** ← בחרו את המאגר. השאירו את ההגדרות כפי שהן (Netlify קורא את `netlify.toml`).
3. **לפני הפריסה הראשונה** (או מיד אחריה): Site configuration → **Environment variables**, והוסיפו:

| משתנה | חובה? | ערך |
|---|---|---|
| `SESSION_SECRET` | **חובה** | מחרוזת אקראית ארוכה (32 תווים ומעלה). לא לשתף! |
| `ADMIN_EMAIL` | **חובה** | המייל שלכם – החשבון שיהיה מנהל |
| `ADMIN_SETUP_CODE` | **חובה** | קוד הקמה סודי שתמצאו (למשל 12 תווים). הוא רק מאפשר ליצור את חשבון המנהל הראשון |
| `SITE_URL` | מומלץ | כתובת האתר המלאה (למשל `https://my-site.netlify.app`), משמשת בקישורים שבמיילים |
| `CONTACT_EMAIL` | מומלץ | כתובת ליצירת קשר שמוצגת בדפי הפרטיות ובתחתית האתר |
| `RESEND_API_KEY` + `FROM_EMAIL` | לאימות מייל ואיפוס סיסמה | שליחת מיילים למשתמשים דרך resend.com. **חשוב:** כדי לשלוח לכל משתמש צריך לאמת דומיין ב-Resend ולהשתמש בכתובת ממנו (`FROM_EMAIL=noreply@הדומיין-שלך`). כתובת הניסיון `onboarding@resend.dev` שולחת רק אליכם |
| `TURNSTILE_SITE_KEY` + `TURNSTILE_SECRET` | אופציונלי | בדיקת "אני לא רובוט" של Cloudflare (חינם) בהרשמה |
| `GOOGLE_CLIENT_ID` | אופציונלי | להתחברות עם Google (ראו למטה) |
| `VAPID_PUBLIC`, `VAPID_PRIVATE` | אופציונלי | התראות דחיפה לדפדפן (זוג מפתחות ES256 בפורמט base64url; בלעדיהם הכפתור 🔔 לא מופיע) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | אופציונלי | התראות בטלגרם |
| `DISCORD_WEBHOOK_URL` | אופציונלי | התראות בדיסקורד: תקלות, דיווחים, הצעות, סריקת בריאות יומית והודעה אחרי כל עדכון (תוסף `netlify/plugins/discord-deploy`) |
| `WHATSAPP_PHONE` + `WHATSAPP_APIKEY` | אופציונלי | התראות תקלה בוואטסאפ (CallMeBot). נשלחות רק הודעות תקלה ואבטחה |
| `NOTIFY_EMAIL` | אופציונלי | כתובת שמקבלת התראות מנהל במייל (דורש גם `RESEND_API_KEY`) |

4. הריצו פריסה מחדש (Deploys → Trigger deploy) אחרי הוספת המשתנים.

**חלופה בלי GitHub:** התקינו Netlify CLI ואז `netlify deploy --prod` מתוך התיקייה (נדרש Node.js).
> גרירת תיקייה לאתר ידנית ("Deploy manually") לא תריץ את השרת, ולכן לא מתאימה כאן.

## יצירת מנהל ראשון
1. פתחו את האתר ← **👤 התחברות** ← "אין לי חשבון – הרשמה".
2. מלאו שם, **את המייל שהגדרתם ב-`ADMIN_EMAIL`** וסיסמה (8 תווים ומעלה).
3. פתחו את החלק **"הקמת מנהל"** והכניסו את `ADMIN_SETUP_CODE`.
4. נכנסתם כמנהל. יופיע כפתור **🛠** שמוביל ללוח הבקרה.
5. אחרי שנוצר המנהל מומלץ למחוק את `ADMIN_SETUP_CODE` מהמשתנים.

> בלי קוד ההקמה, גם מי שנרשם עם המייל שלכם לא יהפוך למנהל (הגנה מפני השתלטות).

## מה חדש בגרסה הזו
* **איפוס סיסמה** ("שכחתי סיסמה") וקישור לאיפוס בתוקף שעה. בלי הגדרת מייל, הקישור נשלח למנהל בטלגרם/דיסקורד כדי להעביר ידנית.
* **אימות כתובת מייל** (ניתן להפוך לחובה לפני הורדה בהגדרות).
* **דפי פרטיות ותנאי שימוש**, אישור בהרשמה, הודעת עוגיות, והורדה/מחיקה של הנתונים האישיים מחלון החשבון.
* **הגנה מספאם והרשמות מזויפות:** הגבלת קצב לפי כתובת IP, שדה-מלכודת לבוטים, זמן מינימום למילוי הטופס, חסימת מיילים זמניים, ובדיקת אנושיות אופציונלית. **כל אירוע חשוד נרשם ביומן ושולח לך התראה** (עד אחת ל-10 דקות לכל סוג אירוע).
* **בדיקת שלמות המודל** לפני ההורדה (קצוות פתוחים) וחיווי "בונה מודל…" בזמן חישוב.
* **כרטיס משתמש מלא** בלוח הבקרה, ו**שליחת הודעות** (באתר ובמייל) למשתמש אחד או לכולם.

## לוח הבקרה
* **סקירה:** מבקרים, משפך שימוש לכל כלי (פתיחה ← שאלון ← מודל ← הורדה), גרף יומי, מדינות פופולריות, הצלחת הדפסות, שגיאות מהדפדפן.
* **משתמשים:** (לחיצה על שם פותחת כרטיס מלא) חיפוש, חסימה, תפקיד (משתמש / עורך לקריאה בלבד / מנהל), מכסה אישית, איפוס מכסה, מחיקה.
* **הזמנות:** יצירת קודי הזמנה (כמות ושימושים). מצב "הרשמה רק עם קוד" מופעל בלשונית הגדרות.
* **דיווחים:** דיווחי "בעיה" מהמשתמשים, עם קישור שפותח את הפרויקט שלהם בדיוק.
* **הודעות:** שליחה למשתמש אחד או לכולם, באתר ובמייל (למי שלא ביטל).
* **אבטחה:** יומן אירועים חשודים שנחסמו.
* **משוב:** אחרי כל הורדה, כשחוזרים לאתר, המשתמש נשאל אם ההדפסה הצליחה.
* **הגדרות:** כלים שמוצגים, הודעה לכולם, מצב תחזוקה, מכסה יומית, התראות. **כל שינוי נשמר בהיסטוריה** ואפשר לשחזר.
* **יצוא (בתוך לשונית "גיבויים"):** CSV של משתמשים, הורדות ודיווחים.

## התחברות עם Google (אופציונלי)
1. console.cloud.google.com ← APIs & Services ← Credentials ← Create credentials ← **OAuth client ID** (Web application).
2. ב-Authorized JavaScript origins הוסיפו את כתובת האתר (`https://...netlify.app` והדומיין שלכם).
3. העתיקו את ה-Client ID לתוך `GOOGLE_CLIENT_ID` ב-Netlify. כפתור Google יופיע בחלון ההתחברות.

## התראות
* **טלגרם:** צרו בוט דרך @BotFather ← העתיקו את ה-token. שלחו הודעה לבוט, ואז פתחו `https://api.telegram.org/bot<TOKEN>/getUpdates` כדי לראות את ה-chat id.
* **דיסקורד:** Server settings ← Integrations ← Webhooks ← העתיקו את הכתובת.
* **מייל:** חשבון חינם ב-resend.com, מפתח API, ו-`NOTIFY_EMAIL` לכתובת שמקבלת.
* בלשונית הגדרות אפשר לבחור על מה להתריע. הדוח השבועי נשלח אוטומטית לכל הערוצים שהוגדרו.

## אם ההתחברות לא עובדת (פתרון תקלות)
1. **פתחו `https://האתר-שלכם/health.html`.** זה דף בדיקה שמראה בירוק/אדום מה תקין ומה חסר (השרת, האחסון, משתנים, חשבון מנהל) ומה לעשות.
   אם הדף כותב "השרת לא עונה": האתר כנראה הועלה בגרירה ולא דרך GitHub/CLI, ולכן אין לו שרת. יש לפרוס מחדש דרך GitHub (ראו "פריסה").
2. **משתנים:** אחרי הוספה או שינוי של משתנים ב-Netlify חובה לבצע **Deploys ← Trigger deploy ← Deploy site**.
3. **לא הצלחתם להיכנס ללוח הבקרה?** יש שתי דרכים להפוך למנהל:
   * להירשם עם המייל ששמתם ב-`ADMIN_EMAIL` ולפתוח "הקמת מנהל" בטופס ההרשמה, או
   * אם כבר נרשמתם: להתחבר, ללחוץ על השם למעלה ← **"יש לי קוד הקמה של מנהל"**, ולהכניס את `ADMIN_SETUP_CODE`. אפשר גם מדף `/admin.html` עצמו.
   המייל חייב להיות זהה (אותיות גדולות/קטנות לא משנות) למה שהוגדר ב-`ADMIN_EMAIL`.
4. **חברים לא מצליחים להירשם?** בדקו שהסיסמה באורך 8 תווים לפחות ושסימנו "אני מאשר/ת". יש הגבלה של 15 הרשמות בשעה מאותה כתובת רשת (למשל אותו Wi-Fi), ולכן בבדיקה עם הרבה חברים ביחד ייתכן שתיתקלו בה.
5. **שגיאה "שגיאת שרת: ..."**: הטקסט אחרי הנקודתיים נותן רמז. פרטים מלאים ב-Netlify ← Logs ← Functions.

## חשוב לדעת (מגבלות ואבטחה)
* **נבדק:** הקוד של השרת עבר 88 בדיקות אוטומטיות, והאתר ולוח הבקרה נבדקו בדפדפן אמיתי מול שרת מקומי עם זיכרון זמני: הרשמה, כניסה, איפוס סיסמה, אימות מייל, מכסות, חסימה, הזמנות, תפקידים, הודעות, ייצוא ומחיקת חשבון, הגנות ספאם, משוב, דיווחים והיסטוריית הגדרות.
* **לא נבדק:** פריסה בפועל ב-Netlify, האחסון האמיתי (Netlify Blobs), התחברות עם Google, שליחת מיילים אמיתית (Resend), בדיקת Turnstile והתראות בטלגרם/דיסקורד, כי לא הייתה לי גישה לרשת. גם בדיקת השלמות של המודלים נבדקה רק על מודלים פשוטים ולא על מודלים אמיתיים, ויכולות להופיע בה התראות שווא. אם משהו לא עובד אחרי הפריסה, בדקו את ה-Function logs ב-Netlify ושלחו לי את השגיאה.
* **המכסה לא אכיפה מוחלטת:** המודלים נוצרים בדפדפן של המשתמש, והשרת סופר ומגביל את הלחיצה על "הורדה". משתמש טכני יכול לעקוף ולייצר קבצים בלי לעבור בשרת. אכיפה מלאה דורשת יצירת הקבצים בשרת.
* **סיסמאות** נשמרות מוצפנות (scrypt), ההתחברות בעוגייה מאובטחת, ויש נעילה אחרי 5 ניסיונות כושלים. עדיין כדאי להשתמש בדומיין עם HTTPS (ברירת המחדל של Netlify).
* **פרטיות:** האתר שומר מייל, שם, סיסמה מוצפנת, פרויקטים שנשמרו ויומן הורדות. הוספתי נוסח כללי לדפי `privacy.html` ו-`terms.html`: זו נקודת פתיחה בלבד, ויש להתאים אותה ולהיוועץ בעורך דין לפני שימוש מסחרי או בקהל מהאיחוד האירופי.
* **חיפוש מקומות** משתמש בשירות החינמי Nominatim של OpenStreetMap, המיועד לשימוש קל. לעומס גבוה כדאי לעבור לשירות בתשלום.
* **רשימת המדינות והדגלים** נטענים מספריות חיצוניות (cdnjs). אם אחת נחסמת, תופיע הודעה והאתר יציג רק ישראל ואיטליה.

## עדכון v3 – מה נוסף

- **קישור קסם (Magic link)** – התחברות במייל בלי סיסמה (דורש RESEND_API_KEY).
- **גיבויים מוצפנים** – בלשונית "גיבויים": יצירה, הורדה ושחזור. מוצפן ב-AES-256-GCM עם `BACKUP_KEY` (אם לא הוגדר – נגזר מ-`SESSION_SECRET`).
  **אל תשנה את SESSION_SECRET/BACKUP_KEY** אחרי שיש גיבויים, אחרת לא ניתן יהיה לפענח אותם. נשמרים 4 גיבויים אוטומטיים אחרונים.
- **דו"ח שבועי** – פונקציית `weekly` שולחת CSV שבועי (ואת הגיבוי המוצפן) לערוצי ההתראות.
- **יומן פעולות (Audit)** – כל פעולת מנהל נרשמת.
- **סביבת בדיקות (Staging)** – כל deploy שאינו production (branch / deploy preview) משתמש ב-store נפרד `trip3d-staging`, מציג סרט "בדיקה", וחסום משליחת מיילים אלא אם הוגדר `STAGING_MAIL`.
- **משוב מפורט** – מדפסת / חומר / סלייסר, וטבלאות אחוזי הצלחה בלשונית "משוב".
- **דיווח על בעיה, מדריך (guide.html), שיתוף כתמונה, חיפוש OSM, המשך עבודה אחרי התחברות, שורת מכסה.**
- כפתור השפה תמיד למעלה וגלוי, גם במובייל.
- משתני סביבה חדשים: `BACKUP_KEY`, `STAGING_MAIL`, `CONTACT_EMAIL`, `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET`, `GOOGLE_CLIENT_ID`.

בדיקות: 118 בדיקות backend עברו מקומית. לא נבדק על Netlify אמיתי – אחרי הפריסה היכנס ל-`/health.html`.

## עדכון v4

- **התראת שגיאות במייל בלבד:** כשיש מעל X שגיאות בשעה (ברירת מחדל 5, ניתן לשינוי בהגדרות) נשלח מייל אחד לכתובת `NOTIFY_EMAIL` (ואם לא הוגדרה – `ADMIN_EMAIL`). לכל היותר מייל אחד בשעה. דורש `RESEND_API_KEY` ו-`FROM_EMAIL`. נספרות גם שגיאות שרת (500).
- **מצב מהיר:** זיהוי אוטומטי של מכשיר חלש/נייד (פחות רינדור, ללא החלקת קצוות, פישוט נקודות זעירות). כפתור "⚡ מצב מהיר / ✨ איכות מלאה" מחליף ידנית.
- **נגישות:** קישור "דלג לתוכן", תוויות לשדות וכפתורים, ניווט מקלדת בכרטיסי הכלים, Escape סוגר חלונות, מסגרת פוקוס, כיבוד `prefers-reduced-motion`.
- **גלריית קהילה:** `/gallery.html`. משתמשים מחוברים מפרסמים (כפתור "🌍 פרסום בגלריית הקהילה"), היצירה ממתינה לאישור בלשונית "גלריה" בלוח הבקרה. אפשר לבחור אם להציג שם, ואם לאפשר פתיחה כתבנית. מחיקת חשבון מוחקת גם את היצירות.
- **תצוגת שיתוף (Open Graph):** תגים באתר ובגלריה, ותמונת `og.jpg`. קישור `/g/<id>` ליצירה מציג תמונה ושם בוואטסאפ. **חשוב:** הגדירו `SITE_URL` ב-Netlify (למשל `https://your-site.netlify.app`) – סקריפט הבנייה `scripts/inject-site-url.mjs` מכניס אותו לתגים.
- **משפך המרה** בלשונית "סקירה": מבקרים ← פתחו ← שאלון ← נבנה ← לחצו הורדה ← התחברות ← הורדו ← משוב, כולל זיהוי נקודת הנפילה הגדולה. נכלל גם בדוח השבועי.

## Cloudflare (חלופה ל-Netlify, בלי מגבלת קרדיטים)

הקוד רץ גם על Cloudflare Workers: קבצים סטטיים מ-`public/`, מסד נתונים D1, ומשימות מתוזמנות (גיבוי יומי + סיכום שבועי).

1. פותחים חשבון חינם ב-cloudflare.com.
2. **Workers & Pages → Create → Import a repository** → GitHub → `eitanb25-maker/trip3d-site`.
3. Deploy command: `npx wrangler deploy` (השאר ברירת מחדל).
4. מסד נתונים: אם לא נוצר אוטומטית – **Storage & databases → D1 → Create** בשם `trip3d`, ואז לשלוח את ה-Database ID, ולהוסיף אותו ל-`wrangler.jsonc` בשדה `database_id`.
5. **Settings → Variables and Secrets** – להוסיף: `SESSION_SECRET` (לפחות 32 תווים), `ADMIN_EMAIL`, `ADMIN_SETUP_CODE`. אופציונלי: `SITE_URL`, ושאר המשתנים מ-`.env.example`.
6. נכנסים לאתר, נרשמים עם `ADMIN_EMAIL`, ופותחים `/health.html` לבדיקה.

נבדק רק מקומית עם סימולציה של D1; ההרצה האמיתית ב-Cloudflare עוד לא נבדקה.

### אם בלוח של Cloudflare אין אפשרות להוסיף סודות
האתר יוצר `SESSION_SECRET` לבד ושומר אותו במסד. את מנהל האתר מגדירים בקונסולה של D1 (Storage & databases → D1 → trip3d → Console):

```sql
INSERT INTO kv (k, v) VALUES ('sys/env', '{"ADMIN_EMAIL":"you@example.com","ADMIN_SETUP_CODE":"קוד-לבחירתך"}') ON CONFLICT(k) DO UPDATE SET v = excluded.v;
```
(אם הטבלה `kv` עדיין לא קיימת, פותחים קודם את האתר פעם אחת.) המפתח `sys/env` לא נכלל בגיבויים.

### עוזר AI עם Gemini (חינם, בלי כרטיס אשראי)
מפתח מ-aistudio.google.com/apikey. ב-Cloudflare, בקונסולת D1:
```sql
UPDATE kv SET v = json_set(v, '$.GEMINI_API_KEY', 'המפתח-שלך') WHERE k = 'sys/env';
```
(אופציונלי: `GEMINI_MODEL`; ברירת המחדל `gemini-flash-latest`.) אחר כך מדליקים את העוזר בהגדרות לוח הבקרה. אם קיים גם `ANTHROPIC_API_KEY`, הוא מקבל עדיפות.
